A modern Business Intelligence dashboard built with Python, Streamlit,
Plotly and Machine Learning.

## Features

-   Interactive KPI Dashboard
-   Sales Analytics
-   Branch Analytics
-   Product Analytics
-   Customer Analytics
-   Finance Dashboard
-   Ratings Dashboard
-   Sales Prediction
-   CSV / Excel / PDF Export
-   Responsive UI

## Installation

``` bash
git clone https://github.com/akash098p/AI-Supermarket-Sales-Analytics
cd Supermarket-Sales-Dashboard
python -m venv .venv

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
streamlit run app.py
```
